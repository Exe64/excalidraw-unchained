# Bibliothèque de formes par défaut — document de travail

État actuel : **aucune forme n'est intégrée**. La bibliothèque d'un nouvel utilisateur est vide ; le bouton « Parcourir les bibliothèques » ouvre le catalogue communautaire (libraries.excalidraw.com, configurable via `VITE_APP_LIBRARY_URL`).

Objectif : fournir une bibliothèque de départ, servie par le serveur, avec les catégories retenues ci-dessous. Cocher / compléter / supprimer librement.

## Points à trancher

- **Source des formes** : dessinées spécifiquement pour l'instance, ou reprises de bibliothèques communautaires (vérifier la licence de chacune avant import).
- **Logos de marques** (Nutanix, VMware, AWS…) : leurs chartes graphiques limitent souvent la réutilisation ; préférer des pictogrammes génériques étiquetés.
- **Style** : trait « dessiné à la main » d'Excalidraw ou trait net (« architecte »).
- **Distribution** : une bibliothèque commune à tous les utilisateurs, ou un jeu de départ copié dans la bibliothèque personnelle de chaque nouvel utilisateur.
